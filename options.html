关于数据和本地加密

点击生成后，仅将目标推文文字、提示词和生成偏好发送到你配置的模型服务。API Key 仅发送至该服务用于认证。插件没有中转服务器，不读取账号密码，不自动发布。

使用 AES-GCM 加密密钥，加密用的不可导出 CryptoKey 存在扩展本机 IndexedDB 中。这能避免明文落盘，但不能抵御已控制本机或扩展运行环境的攻击者。更换服务或 API 地址后需重新填写密钥。
